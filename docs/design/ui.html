Treader 界面设计稿（RickyOS 风格）

按小纸 Pico 屏幕真实像素（684×1216）绘制，缩小一半显示。风格参照 RickyOS：顶部状态栏，底部四个图标标签页；不用粗框和按钮堆叠，靠细线、留白和字重分层；没有图片封面，用“文字封面”（双线框里排书名、作者和格式）代替。只用黑、白、浅灰三种灰阶。

系统

番茄小说

和上一版比改了什么

  • 导航：去掉右下角菜单按钮和全屏菜单，改成底部四个标签页：首页、书库、番茄、设置。阅读时标签栏隐藏。
  • 视觉：不再每一行都套圆角框，改用细分隔线、留白和字重；黑色胶囊只用在主操作上（当前标签、主按钮）。
  • 封面：用文字生成，不解码图片，速度和内存都没有额外开销。
  • 新增：首页、状态栏、锁屏书卡、书籍详情的简介（数据来自搜索结果，不需要额外请求）。

实现上要注意

项目说明
工作量比上一版大：要新写一套绘制原语（标签栏、文字封面、虚线进度条、胶囊按钮、线条图标），并把书架、阅读工具、设置等官方页面改成新排版。官方的阅读排版、字体渲染、刷新策略、传书服务不动。
图标9 个线条图标做成 40×40 的 1-bit 位图编进固件，几 KB。
时间设备没有联网对时，状态栏和首页日期要等番茄同步时顺便用 SNTP 对一次时，之前只显示电量。
刷新切换标签用整页 GL16；进度、键盘、候选条用局部 DU；每 N 次整页刷新做一次 GC16 清残影，沿用官方均衡档。
