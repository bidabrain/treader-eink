Treader 界面与功能（0.5.0）

这是 Treader 当前版本（0.5.0）的完整界面和功能说明，是唯一的界面设计稿。按小纸 Pico 的真实像素（684×1216）和代码里的坐标绘制，缩小一半显示；图片封面、壁纸和帖子图片用灰度渐变示意，真机上是抖动成 16 级灰度的实际图片。 底部标签页：书库、漫画、番茄、小红书、虎扑、微博、设置，最多同时显示七个（设置 › 底部标签里可以关掉中间五个，㉟）。微博（W1～W5）和内容来源按来源分页（㊸）是 0.5.0 之后新加的，还没在真机上验证；设置改成六个分类（㉞），小红书（㊻～㊿）、网页填写（㊹㊺）和 USB 传书（U1～U5）是 0.5.0 新加的。漫画（⑦～⑩）、上传漫画（⑮～⑰，设备屏幕和手机网页各一边）、自动翻页和隐藏虎扑是 0.4.0 新加的，还没在真机上验证。自动锁屏和锁屏密码（L1～L4）是 0.7.0 新加的，还没在真机上验证。时间与时区（T1、T2）是 0.7.1 新加的，还没在真机上验证。在线升级（O1、O2）是 0.8.0 新加的，还没在真机上验证。没有画出来的页面和全局规则写在最后。

设置

其他页面（无示意图）

  • 目录：阅读工具条点“目录”。每页 10 章，正在读的那章右边标“在读”，点一章跳过去，翻页同书库。
  • 图书详情：书库里长按一本书。显示完整书名、格式、大小和进度，可以分别“清进度”和“删除文件”（各要再确认一次）；番茄书删除时一起删掉封面缓存和番茄书架记录。
  • 书库搜索：书库右上角放大镜。默认英文键盘，按拼音首字母、全拼或英文匹配书名；结果在书库里显示，筛选条出现“关键词 ×”，点掉恢复。
  • 管理书库：书库筛选条点“管理”。多选后批量删除或清进度，还有本页全选、清除勾选、重新扫描。
  • 菜单：一般页面按右键（或点右下角把手）打开，列出书库、漫画、番茄、虎扑、设置五个主页面（隐藏虎扑后是四个），再按一次关闭。
  • 漫画详情：漫画书架长按一部、或系列里长按一话进来。显示话数或文件大小和进度，可以清进度，或删除（再点一次确认；删系列会删掉文件夹里的全部 CBZ）。
  • WiFi 密码键盘 / 遗忘确认：选择 WiFi（⑫）里点一个需要密码的网络进密码键盘，最多 64 个字符，可切换显示；“遗忘网络”先进确认页。
  • 字体：设置 → 字体。列出 TF 卡 fonts/ 里的 TTF，选字体和字重，没有字体时用内置小字库。
  • 睡眠与锁屏：设置 → 睡眠与锁屏。电源键短按时用浅睡、深睡还是关机；浅睡可选“拿起唤醒”。
  • 番茄服务器 / 书城榜单 / WebDAV：设置里对应的行，用屏幕键盘填地址、密码。番茄服务器留空就用编译进固件的内置服务器（只显示“内置服务器”，不露地址和密码）；书城榜单留空用默认地址。
  • 立即同步：设置 → 立即同步。用 WebDAV 同步阅读进度和番茄书架，书本身不传；结果写在设置标题右边。
  • 设备信息 / 设备自检：关于 Treader 页底部。设备信息是官方的概览页（I²C 设备、识别码、电池、构建时间）；设备自检逐项检查电源管理芯片和各个外设（探测是真测，其余看芯片应答）。

全局规则

  • 翻页不滚动：所有列表、正文、回复都按页显示，点“‹ ›”或滑一下（左 / 上滑下一页，右 / 下滑上一页）翻一整页。阅读正文还可以点左右两侧或按左右键。
  • 刷新：翻页用 DU 局部快刷，积累几次后自动整页刷新压残影；长按中键 0.5 秒随时整屏刷新。
  • 只在点的时候联网：番茄检查更新、下载，书城刷新，虎扑刷新，同步，都只在用户操作时联网，做完就断开；不会后台自动联网。打开没有缓存的内容（书城分类、虎扑帖子 / 专区 / 赛程）时会自动取一次。
  • 不联网也能用：书库、阅读不需要网络；番茄书架、书城、虎扑都先显示 TF 卡上的缓存，没有缓存就提示“联网后点刷新”。
  • 失败提示带原因：联网失败时提示后面括号写具体原因，如“未设置 Wi-Fi”“密码不对或信号太弱”“传书还在占用 Wi-Fi”“域名解析失败”“HTTPS 握手失败”“连接服务器超时”“HTTP 404”。一行放不下就换两行显示。
  • 国内网络：Wi-Fi 按中国信道（1～13）。路由器 DNS 解析失败时自动改用阿里 223.5.5.5 / 腾讯 119.29.29.29 再试；书城直连 GitHub Pages 超时会自动改用 jsDelivr 镜像。
  • 锁屏：电源键短按锁屏，空闲 2 分钟自动锁屏；同步、升级、传书期间不自动锁屏。
  • 存储预留：传书和上传漫画时，TF 卡至少留下 100 MB 和卡容量 5% 中较大的那块，网页和设备上显示的“可上传”已经扣掉它。
  • TF 卡：书、漫画、封面、缓存都只放 TF 卡；书在 books/，漫画在 comics/，两边进度分开存。拔卡不会死机，重新插卡自动挂载。
