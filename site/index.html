为墨水屏
重新设计的阅读系统

本地 TXT / EPUB、CBZ 漫画、番茄小说，再加上小红书、微博、虎扑——全部为 4.7 寸 16 级灰度屏和 ESP32-S3 重新排版。浏览器里就能刷机，固件文件不会离开你的电脑。

不只是 Pico 上的固件：番茄小说、小红书、微博各有一个安卓 App，黑白灰度、按页翻、和设备一样的排版，在手机上也是墨水屏的阅读体验；番茄的阅读进度和书架还能用 WebDAV 和 Pico 互通。

FEATURES

一台阅读器，该有的都在

所有列表都按页翻，不做滚动；联网的内容都先缓存到 TF 卡，没网也能看已经下好的。

书库与阅读

TXT、EPUB 书架和封面，拼音首字母搜索；行距、段距、页边距都能调，逐书记住进度，定时自动翻页。

漫画

CBZ 按系列整理，一屏一页，一话看完自动接下一话；网页上传时先转成灰度，翻页更快。

番茄小说

搜索、下载、检查更新，书城按榜单分类浏览；下载好的书和普通书一样在书库里读。手机上有同样功能的安卓 App。

小红书

关注博主和首页推荐，两列封面卡片；看图一屏一张，再看正文和评论，大图还能存成锁屏壁纸。

经自建 rednote 服务器

微博

关注的人和热门，卡片排版、转发灰框、图片宫格；长微博补全文，评论按需取。不用登录微博。

经自建 weibo 服务器

虎扑

推荐、关注专区、比分和球员评分，帖子和“亮了”回复；不登录、不需要服务器。

传书

Wi-Fi 网页上传书、字体和漫画；或者用数据线把 TF 卡当 U 盘直接拷。

同步与升级

WebDAV 同步阅读进度和番茄书架；TF 卡放好固件就能升级，起不来自动退回旧版。

SCREENS

按设备真实像素设计的界面

每一屏都按 684×1216 的实际坐标绘制，图片用灰度渐变示意，真机上是抖动成 16 级灰度的实际图片。

全部页面和每一屏的说明见 设计稿（下载后用浏览器打开）。

ECOSYSTEM

自己的服务器，自己的数据

设备不直接访问番茄、小红书和微博，只连你自己用 Docker 部署的服务器，每个都带网页面板和 Cloudflare 隧道；小红书和微博的服务器还会把图片处理成墨水屏能直接显示的灰度图。三个服务器各配一个安卓 App，功能和界面照固件做：黑白灰度、按页翻，没有 Pico 也能在手机上用，有 Pico 就两边一起用。

tomato · 番茄下载服务器

  • 官方 Tomato-Novel-Downloader + 面板，一个 compose 部署
  • 设备密码在面板里管，外网只放行设备接口
  • 安卓 App：书库、搜书下载、书城、按页阅读，进度和书架用 WebDAV 和 Pico 互通
部署说明 安卓 App

rednote · 小红书服务器

  • 扫码登录小红书网页版，定时拉关注博主的图文
  • 推荐只在设备上点“刷新”时才去读
  • 关注名单可以 WebDAV 备份恢复；隧道只开放设备接口

weibo · 微博服务器

  • 不登录，访客身份定时拉关注的人和热门
  • 带视频的不收，长微博补全文，评论按需取
  • 关注名单和 weiboX 用同一个 WebDAV 备份文件

INSTALL

在浏览器里刷机

用电脑上的 Chrome 或 Edge，USB-C 数据线连上小纸 Pico，三步完成。小纸 Pico 没有 BOOT 键，网页会自动让它进入下载模式。

下载最新固件

GitHub Actions 在固件每次改动后自动编译发布，用和真机一样的配置，可以直接刷进小纸 Pico。下载后拖到下面第 1 步。

番茄小说需要自建服务器

下载的固件不带番茄下载服务器。阅读、漫画、虎扑、书城榜单、传书都能直接用；要搜索和下载番茄小说，用本项目的 番茄服务器一键部署（官方 Tomato-Novel-Downloader + 面板，docker compose up -d 就行），再在设备“设置 › 内容来源 › 番茄小说”填面板上显示的地址和密码。小红书、微博也各需要自建服务器（见上面“服务器与 App”）。

这个浏览器不支持网页串口（Web Serial）。请用电脑上的 Chrome 或 Edge 打开本页；手机和 Safari、Firefox 都不行。

刷机说明

          
    
            
  • 点“连接设备并开始”，在弹窗里选设备的串口（通常叫 USB JTAG/serial debug unit）。
    • 
            
  • 写入约 1～2 分钟，完成前不要拔线。完成后设备会自动重启。
    • 
            
  • 小纸 Pico 没有 BOOT 键，不用按任何键。设备要先开机（锁屏选“关机”时 USB 不工作）。
    • 
            
  • 连接不上：换一根能传数据的线（官方建议 USB-A 转 C）；关掉占用串口的程序（串口监视器、别的刷机页）；拔插 USB；让设备睡眠再唤醒一次，或关机重开。
    • 
            
  • 固件用上面下载的，或者自己编译的 build/treader-full.bin（build/Read_Pico.bin）。自己编译时可以把番茄服务器内置进去，见 项目说明；这样编出的固件不要公开。
    • 
            
  • 第一次刷机后，TF 卡需要放好 fonts/（中文字体）和 ime/（拼音词库）。
