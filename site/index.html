小纸 Pico · Read Pico 开源阅读固件 · 安卓 App

为墨水屏
重新设计的阅读系统

本地 TXT / EPUB、CBZ 漫画、番茄小说，再加上小红书、微博、虎扑——全部为 4.7 寸 16 级灰度屏和 ESP32-S3 重新排版。浏览器里就能刷机，固件文件不会离开你的电脑。

不只是 Pico 上的固件：番茄小说、小红书、微博各有一个安卓 App，黑白灰度、按页翻、和设备一样的排版，在手机上也是墨水屏的阅读体验；番茄的阅读进度和书架还能用 WebDAV 和 Pico 互通。还有离线的两步验证码：设备上的验证器，加上能把账号发送到 Pico 的安卓 App。

FEATURES

一台阅读器，该有的都在

所有列表都按页翻，不做滚动；联网的内容都先缓存到 TF 卡，没网也能看已经下好的。底部放常用的几个功能，其余都在“全部”里；字嫌小可以把显示大小调到大或特大。

书库与阅读

TXT、EPUB 书架和封面，拼音首字母搜索；行距、段距、页边距都能调，逐书记住进度，定时自动翻页。

漫画

CBZ 按系列整理，一屏一页，一话看完自动接下一话；网页上传时先转成灰度，翻页更快。

番茄小说

搜索、下载、检查更新，书城按榜单分类浏览；下载好的书和普通书一样在书库里读。手机上有同样功能的安卓 App。

小红书

关注博主和首页推荐，两列封面卡片；看图一屏一张，再看正文和评论，大图还能存成锁屏壁纸。

微博

关注的人和热门，卡片排版、转发灰框、图片宫格；长微博补全文，评论按需取。不用登录微博。

经自建 weibo 服务器

虎扑

推荐、关注专区、比分和球员评分，帖子和“亮了”回复；不登录、不需要服务器。

传书

Wi-Fi 网页上传书、字体和漫画；或者用数据线把 TF 卡当 U 盘直接拷。

同步与升级

WebDAV 同步阅读进度和番茄书架；设备上点“检查更新”就能在线升级（先下到 TF 卡，断了接着下，校验通过才写入），也可以把固件放进 TF 卡升级，起不来自动退回旧版。

发现漫画 · WEBTOON 追更

我的漫画右上角的“发现”里逛 WEBTOON 的排行、类型、星期更新表和已完结，搜作品名（打简体也能搜到繁体中文版）；订阅后点“检查更新”，新话下载成 CBZ 放进我的漫画，和本地漫画一起看。手机上有同样功能的安卓 App。

部署说明 安卓 App
  • 服务器把一话的竖长条转成灰度，在分镜之间的空白处按屏幕切页，不把画格和对白切成两半；翻页和本地漫画一样快
  • 订阅只存在设备 TF 卡上（作品文件夹里一个标记文件），服务器不保存；换服务器、重装都不丢
  • 我的漫画里按 全部 / 本地 / WEBTOON 筛选，订阅的封面标“WT”，新下好没看的写“N 话新”
  • 只拉网页上公开免费的话，不登录、不碰付费；请自己部署、只给自己用

验证器 · 两步验证码

离线显示 TOTP 两步验证码，和 Google Authenticator 算出的一样，不连任何服务器。从 1.0.0 起在“全部”里；手机上有同样功能的安卓 App，能把账号直接发送到小纸 Pico。

使用说明 安卓 App
  • 账号用验证器口令加密在 TF 卡上，要口令加上这台设备才解得开；口令和开机密码分开
  • 导入：设备开热点，手机网页里扫 Google Authenticator 导出的二维码、粘贴 otpauth 链接或手填密钥，在设备上点“导入”才写入
  • 每次锁屏、重启都会上锁，也可以设成离开验证器 5 分钟就上锁；口令输错多次要等待，逐次加倍
  • 请一直保留手机上的验证器作备份：不导出密钥、不做云同步，忘了口令只能清空重来

ECOSYSTEM

自己的服务器，自己的数据

设备不直接访问番茄、小红书和微博，只连你自己用 Docker 部署的服务器，每个都带网页面板和 Cloudflare 隧道；小红书和微博的服务器还会把图片处理成墨水屏能直接显示的灰度图。三个服务器各配一个安卓 App，功能和界面照固件做：黑白灰度、按页翻，没有 Pico 也能在手机上用，有 Pico 就两边一起用。

tomato · 番茄下载服务器

  • 官方 Tomato-Novel-Downloader + 面板，一个 compose 部署
  • 设备密码在面板里管，外网只放行设备接口
  • 安卓 App：书库、搜书下载、书城、按页阅读，进度和书架用 WebDAV 和 Pico 互通
部署说明 安卓 App

rednote · 小红书服务器

  • 扫码登录小红书网页版，定时拉关注博主的图文
  • 推荐只在设备上点“刷新”时才去读
  • 关注名单可以 WebDAV 备份恢复；隧道只开放设备接口
部署说明 安卓 App

weibo · 微博服务器

  • 不登录，访客身份定时拉关注的人和热门
  • 带视频的不收，长微博补全文，评论按需取
  • 关注名单和 weiboX 用同一个 WebDAV 备份文件
部署说明 安卓 App

webtoon · 发现漫画服务器

  • 读 WEBTOON 公开免费的话，不登录、不保存订阅
  • 设备要哪一话才转：灰度、按屏在分镜空白处切页、打包 CBZ
  • 安卓 App：发现页、订阅、检查更新、一屏一页阅读
部署说明 安卓 App
INSTALL

在浏览器里刷机

用电脑上的 Chrome 或 Edge，USB-C 数据线连上小纸 Pico，三步完成。小纸 Pico 没有 BOOT 键，网页会自动让它进入下载模式。

下载最新固件

GitHub Actions 在固件每次改动后自动编译发布，用和真机一样的配置，可以直接刷进小纸 Pico。下载后拖到下面第 1 步。

完整镜像（第一次刷） 升级包 TF 卡文件 全部版本 ›

第一次刷机还要准备 TF 卡：下载“TF 卡文件”（treader-版本-sdcard.zip，含中文字体和拼音词库），解压后把里面的全部内容复制到 FAT32 格式 TF 卡的根目录（不是复制解压出来的文件夹本身）。少了它界面会缺字、不能输入中文。以后升级固件不用再复制。

番茄小说需要自建服务器

下载的固件不带番茄下载服务器。阅读、漫画、虎扑、书城榜单、传书都能直接用；要搜索和下载番茄小说，用本项目的 番茄服务器一键部署（官方 Tomato-Novel-Downloader + 面板，docker compose up -d 就行），再在设备“设置 › 内容来源 › 番茄小说”填面板上显示的地址和密码。小红书、微博也各需要自建服务器（见上面“服务器与 App”）。

书城榜单总是连不上？

书城默认从 GitHub Pages（bidabrain.github.io）取榜单，国内很多时候连不上。可以在设备“设置 › 内容来源 › 番茄小说 › 书城榜单”（番茄安卓 App 在“设置 › 书城榜单”）把地址改成下面这个 jsDelivr 镜像：

https://cdn.jsdelivr.net/gh/bidabrain/FanqieRankTracker@main

镜像最多晚半天更新。也可以 fork FanqieRankTracker 自建榜单（打开 GitHub Pages 后填你自己的网站地址），说明见 书城榜单。

这个浏览器不支持网页串口（Web Serial）。请用电脑上的 Chrome 或 Edge 打开本页；手机和 Safari、Firefox 都不行。

刷机说明

          
    
            
  • 点“连接设备并开始”，在弹窗里选设备的串口（通常叫 USB JTAG/serial debug unit）。
