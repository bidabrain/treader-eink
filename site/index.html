Treader 刷机

在浏览器里给小纸 Pico 刷入 Treader。固件文件只在你的电脑上读取，通过 USB 直接写进设备，不会上传到任何服务器。

这个浏览器不支持网页串口（Web Serial）。请用电脑上的 Chrome 或 Edge 打开本页；手机和 Safari、Firefox 都不行。

说明

    
    
      
  • 用 USB-C 数据线连接小纸 Pico，点“连接设备并开始”，在弹窗里选设备的串口（通常叫 USB JTAG/serial debug unit）。
    • 
      
  • 写入约 1～2 分钟，完成前不要拔线。完成后设备会自动重启。
    • 
      
  • 连接不上：按住 BOOT 键再插 USB 线，进入下载模式后重试；或者换一根能传数据的线。
    • 
      
  • 固件文件来自你自己编译的 build/treader-full.bin（或 build/Read_Pico.bin）。页面会核对文件头，确认是给 ESP32-S3 的 Treader 固件才允许写入。
    • 
      
  • 第一次刷机后，TF 卡需要放好 fonts/（中文字体）和 ime/（拼音词库），详见 项目说明。
    •
