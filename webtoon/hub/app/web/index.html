            E-Hentai 通道

            服务器自己读 e-hentai.org（或 exhentai.org），不用插件。打开后设备和 App 的“来源”里多一个 E-Hentai。一部画廊按下面的张数切成几话，订阅后用“检查更新”下载。成人内容，只给自己用，请遵守站点条款。

            账号（填 cookie 登录）

            不登录也能用 E-Hentai；登录后图片额度更多，也能用 ExHentai。服务器没法替你输账号密码（登录页要过 Cloudflare 验证），所以在能打开 e-hentai.org 的浏览器里登录后，把 cookie 填到这里：开发者工具（F12）→ 应用 / 存储 → Cookie → e-hentai.org，或者网络里任意一个 e-hentai.org 请求的 Cookie 请求头。保存时服务器会拿它试一次能不能用。cookie 只存在服务器上，这里不回显。
