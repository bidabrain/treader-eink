            账号

            登录后图片额度更多，也能用 ExHentai。密码只发给 E-Hentai 换登录 cookie，服务器不保存密码。登录页要过 Cloudflare 验证，要先开 FlareSolverr：在 docker-compose.yml 旁边的 .env 里让 COMPOSE_PROFILES 带上 flaresolverr（比如 COMPOSE_PROFILES=flaresolverr，开了插件的写 mihon,flaresolverr），再 docker compose up -d。不登录也能用 E-Hentai。

            要验证码登录不了？手动填 cookie

            在浏览器登录 e-hentai.org 后，从开发者工具的 Cookie 里复制。留空的不改。
