登录 X

点“打开登录浏览器”，下面会出现服务器上那个浏览器的画面，直接在里面登录（两步验证、验证码都在这里做）。 登录完看到首页后点“登录好了”，服务器会保存登录并关闭画面；以后失效或要求验证时，再来这里登录一次。 这个窗口是一个普通的 Chrome，没有任何自动化控制。

在新窗口打开画面

备用：导入 cookie

登录画面用不了时再用这个。粘贴 Cookie-Editor 导出的 JSON、cookies.txt，或 auth_token=…; ct0=…。 注意：cookie 来自别的网络时，X 更容易要求验证。

清除登录

只清掉服务器这个浏览器里的 X 登录，不影响你在手机和电脑上的登录。

已拉到的推文

广告已去掉；图片已经转成设备用的灰度 JPEG。

正在关注总开关

关掉后正在关注手动、自动都不拉，只拉为你推荐；设备和 App 会探测到，把“正在关注”标签变灰、不能切换。已存的不删。

自动拉取

每次拉完，下一次在最小和最大间隔之间随机取，不会准点。最小间隔不低于 分钟。手动拉取不受这些限制。

回复

滚得越多拿到的回复越多，但设备和 App 第一次打开回复要等更久（每次约多 5～10 秒；总共最多约 45 秒，到时间就停）。只影响以后第一次打开的推文，已经取过的不会重取。

睡眠时段

可以跨零点。醒来后第一次拉取会随机推迟一会儿，不会一到点就拉。时区：服务器的 TZ（默认 Asia/Shanghai）。
